# 実務イメージ型 ポートフォリオ
【概要】  
本ポートフォリオは、設計、実装、試験など、一連の流れを自力で完遂できることアピールすることが目的です。  
採用担当者様の現場で使用する技術のみにフォーカスして、ご確認していただけますと幸いです。
